# Our Little World — веб-игра 0.2 💗

Бесплатный браузерный прототип 3D-песочницы с изометрической камерой. Работает на Windows, Android и iPhone в современном браузере. Это пока не готовая большая игра, а основа, которую можно расширять по шагам.

## Что уже есть
- Изометрический 3D-город: дом, улица, магазинчик, кафе и парк.
- Переключение локаций.
- Показатели энергии, сытости, настроения и близости.
- Действия: готовить еду, спать, убираться, отдыхать, проводить время вместе и читать романтическое письмо.
- Деньги и простая подработка.
- Магазин декора: растения, лампа, диван, цветы, телевизор, кровать, ковёр и книги.
- Инвентарь, размещение декора и сохранение в браузере.
- Имена персонажей можно менять.
- Никаких аккаунтов, платных API или мультиплеера.

## Важно
- При первом открытии нужен интернет: 3D-библиотека Three.js загружается с CDN.
- GitHub Pages тоже требует интернет для открытия сайта.
- Сохранение находится в браузере конкретного устройства. Пока оно не синхронизируется между телефоном и компьютером.
- Игра — ранний прототип: часть локаций пока визуальная, а перемещение и взаимодействия будут улучшаться дальше.
- Не загружай в публичный репозиторий личные фотографии, пароли или токены.

## Как запустить на Windows 10 без установки программ
1. Распакуй ZIP.
2. Открой папку и дважды нажми `index.html`. Если браузер блокирует загрузку 3D-модуля при открытии локального файла, опубликуй игру через GitHub Pages (инструкция ниже).

## Бесплатная публикация через GitHub Pages
1. Войди на https://github.com/ .
2. Нажми **New repository**.
3. Название: `our-little-world`. Выбери **Public** и создай репозиторий.
4. Нажми **Add file → Upload files**.
5. Перетащи `index.html` из этой папки. Можно также загрузить `README_RU.md` и `.nojekyll`.
6. Нажми **Commit changes**.
7. Открой **Settings → Pages**.
8. В **Build and deployment** выбери **Deploy from a branch**, branch `main`, folder `/(root)`, затем **Save**.
9. Подожди несколько минут и открой ссылку, показанную на странице Pages.
10. На iPhone открой ссылку в Safari → кнопка «Поделиться» → «На экран Домой».

## Как играть
- Выбирай локацию в меню.
- Используй действия справа, чтобы менять показатели и получать монеты.
- В магазине покупай декор.
- Включи «Режим декора», затем нажми по 3D-сцене, чтобы добавить предмет.
- Измени имена и нажми «Сохранить имена».
- Кнопка «Начать заново» удаляет локальный прогресс в этом браузере.
